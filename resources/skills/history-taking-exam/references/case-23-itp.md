# 病例 23 · 原发免疫性血小板减少症（血液内科）

**对应建议病种**：血液内科 — 特发性血小板减少性紫癜（ITP）
**难度**：★★★
**主线**：一身瘀斑。考的是"出血三问 + 用药史"，以及会不会把出血问成贫血。

## 二、问诊分层（问到才答，不主动）

**主诉**
- 问哪里不舒服 → "身上起紫点，一片一片的，越来越多了。"
- 追问最在意的 → "刷牙出血，止不住。还有……我这次月经特别多。"（**月经过多不主动说，要问**）

**起病与时间**
- "三个礼拜前发现的。先是腿上几个点，我以为是蚊子咬的印子。"
- 加重："这一个礼拜多起来了，胳膊上、肚子上都有。"
- 追问诱因时间关系：**"起疹子前一个月，我感冒过一回，还打了一针疫苗。"**（**前驱感染/疫苗接种史，重要**）

**出血表现（本题核心，必须逐项问）**
- 皮肤：四肢散在瘀点、瘀斑，压之不褪色；追问——"有没有磕到过？" → "没有，自己就出来了。"
- 鼻出血：追问——"出过两回，一次十几分钟才止住。"
- 牙龈出血：✓ "刷牙就出血，漱口好多遍还有。"
- 口腔血疱：追问——"嘴里有没有血泡" → "没有。"
- 月经过多：✓ **追问才有** ——"以前四五天，这次八九天，量特别大，一天要换七八片，还有大血块。"
- 黑便、便血：✗ **需明确追问**
- 血尿：✗ **需明确追问**
- 咯血：✗
- 头痛、呕吐、视物模糊：✗（**颅内出血筛查，必须问**）
- 关节肿痛、肌肉血肿：✗（排除血友病）
- 外伤后长时间出血：✗
- 拔牙、手术后出血不止：✗

**伴随症状**
- 乏力：✓ "容易累。"
- 头晕：追问——"蹲下起来发黑。"
- 心悸：✓ "上楼心慌。"
- 发热：✗ "不烧。"
- 盗汗：✗
- 骨痛：✗ **需明确追问**

- 关节痛：✗
- 口干眼干：✗
- 反复口腔溃疡：✗

**阴性鉴别（问到才说没有）**

## 三、陷阱设计

1. **核心陷阱：把"出血"问成"贫血"。** 病人说"身上起紫点"，容易被引到"贫血"方向去问头晕乏力。必须区分：这是**出血表现**（瘀点瘀斑、黏膜出血），不是贫血表现。
2. **月经过多藏在"这次月经特别多"里**：不问"月经量有没有变化"不会说；问了还要追"几片卫生巾""有没有血块""几天"。
3. **用药史几乎没人问**：布洛芬、头孢、减肥茶三样都要点名问，问"最近吃什么药了吗"只会得到"没吃什么"。
4. **前驱感染与疫苗接种不主动说**：问"起病前一个月有没有感冒、打针"才吐出来。
5. **颅内出血筛查必须做**：头痛、呕吐、视物模糊三问，很多考生会忘，这是 ITP 最致命的并发症。
6. **怕白血病的情绪**：反复追问"我这是不是白血病"，会打断问诊；同时这也是沟通考点。
7. **主动提问**（中段）："大夫，我这个是不是白血病？我表妹就是白血病，一开始也是身上有紫点。"
8. **主动提问**（总结后）："这个能治好吗？会不会变成慢性的？我还能不能结婚生孩子？"

## 四、既往史 / 个人史 / 家族史 / 社会心理

- 既往：体健；否认肝炎、结核、自身免疫病（SLE、干燥综合征）、HIV；否认血液病史；否认脾大、淋巴结肿大史。
- 长期用药：布洛芬（头痛时服，每月 3–4 次）；上月头孢类抗生素 5 天；曾服"减肥茶"1 个月（成分不明，已停）；否认肝素、奎宁、磺胺、抗癫痫药。
- 手术外伤：无手术；无输血史；无拔牙后出血不止史。
- 过敏：否认。
- 传染病：否认肝炎、结核；否认 HIV 高危行为。
- 预防接种：**1 个月前接种流感疫苗**。
- 个人：不吸烟、不饮酒；办公室工作，无苯及放射线接触；月经规律，量如前述；未婚未育。
- 家族：表妹患"白血病"（具体类型不详）；否认血友病、ITP、自身免疫病家族史。
- 社会心理：独居，父母在外地；怕请长假影响工作；对血液病极度恐惧（亲属患病经历）。

## 五、标准病历（考后对照）

**主诉**：皮肤瘀点瘀斑 3 周，牙龈出血伴月经量增多 1 周。

**现病史**：患者 3 周前无明显诱因发现双下肢散在瘀点，压之不褪色，无外伤史，未重视。1 周来瘀点瘀斑增多，波及双上肢及腹部。伴刷牙后牙龈出血不易止、鼻出血 2 次（每次约 10 余分钟自止）、本次月经量明显增多（经期由 4–5 天延长至 8–9 天，每日卫生巾 7–8 片，伴大血块）。伴乏力、体位性头晕、活动后心悸。1 个月前有上呼吸道感染史并接种流感疫苗。无发热、盗汗、骨痛、体重下降；无黑便便血、无肉眼血尿、无咯血；无头痛、呕吐、视物模糊；无关节肿痛及肌肉血肿、无外伤后长时间出血、无拔牙后出血不止；无面部红斑、光过敏、关节痛、口干眼干、反复口腔溃疡。2 周前社区查血常规示血小板 30×10⁹/L，建议至上级医院未依从，予止血药及中成药口服无效。

**既往史**：体健；否认肝炎、结核、自身免疫病、HIV 感染；否认血液病史。间断服布洛芬（每月 3–4 次）；上月服头孢类抗生素 5 天；曾服成分不明"减肥茶"1 个月。无手术及输血史；否认药物过敏；1 个月前接种流感疫苗。

**个人史**：不吸烟、不饮酒；办公室工作，无苯、放射线接触；未婚未育。

**家族史**：表妹患"白血病"（类型不详）。否认血友病、ITP 及自身免疫病家族史。

**体格检查（要点）**：BP 108/66 mmHg，HR 96 次/分；四肢及腹部散在瘀点、瘀斑，压之不褪色，未见口腔血疱；睑结膜略苍白；巩膜无黄染；口腔黏膜完整；全身浅表淋巴结未触及肿大；胸骨无压痛；心肺未见异常；腹软，肝脾肋下未及；双下肢无水肿；神经系统查体未见异常。

**辅助检查**：血常规：PLT 18×10⁹/L，WBC 6.2×10⁹/L（分类正常），Hb 96 g/L，MCV 82 fL，网织红 1.8%；外周血涂片：血小板明显减少、散在分布、未见大血小板及血小板聚集，红细胞及白细胞形态未见异常，未见原始细胞；凝血功能：PT 11.8 s，APTT 28 s，纤维蛋白原 2.8 g/L（均正常）；抗核抗体、抗 dsDNA、抗心磷脂抗体：阴性；HIV、HCV、HBV：阴性；幽门螺杆菌：阴性；腹部超声：脾不大；骨髓穿刺（待做）：预期巨核细胞增多伴成熟障碍。

**诊断**：1. 原发免疫性血小板减少症（ITP，新诊断，重度血小板减少）；2. 失血性贫血（轻度，考虑月经过多所致）。

**鉴别要点**：急性白血病（多有发热、骨痛、肝脾淋巴结肿大、外周血见原始细胞、骨髓可确诊）；再生障碍性贫血（全血细胞减少、网织红降低、骨髓增生低下）；血栓性血小板减少性紫癜（TTP，伴微血管病性溶血、神经症状、肾损害、发热，ADAMTS13 降低）；弥散性血管内凝血（DIC，凝血指标异常、有诱因）；药物性血小板减少（停药后恢复、有明确用药史）；假性血小板减少（EDTA 依赖性，血涂片见血小板聚集）；系统性红斑狼疮（多系统受累、自身抗体阳性）；脾功能亢进（脾大、全血细胞减少）。

## 六、考官提示

- 本题第一考点是**出血三问**：皮肤（瘀点瘀斑，压之不褪色、无外伤）、黏膜（牙龈、鼻、口腔血疱）、内脏（消化道、泌尿道、颅内）。三处问到两处给 3 分，全问到给 4 分。
- **月经过多**是本题最容易丢的分：必须问"月经量有没有变化""几片卫生巾""有没有血块""几天干净"。
- 「用药史」：布洛芬、头孢、减肥茶三项必须**点名问**，问"最近吃什么药"得不到答案。这一项直接关系到"是原发还是继发"的判断。
- 「阴性鉴别」2.5 分：必须主动问发热、骨痛、肝脾淋巴结（排除白血病/淋巴瘤）、关节痛皮疹口干（排除 SLE）、黑便血尿（评估出血范围）、头痛呕吐视物（排除颅内出血）。
- 「家族史」：问到"表妹是哪种白血病、在哪治、现在怎么样"才算问到，只问"家里有人得过血液病吗"给半分。
- 沟通考点：病人问"我是不是白血病"时，**既不能一口否定也不能顺着吓她**。可接受的处理是说明目前证据指向什么、还需要什么检查才能排除、以及即使是最坏情况也有对应方案。这一项占"医患沟通"2 分。
- 若考生全程没问用药史、没问月经量，本题通常落在 55–68 分。
