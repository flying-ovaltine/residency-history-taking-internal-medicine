# 病例 11 · 急性肾盂肾炎（肾脏内科 / 感染科）

**对应建议病种**：肾脏内科 — 尿路感染
**难度**：★★☆
**主线**：尿路刺激征 + 腰痛 + 发热寒战。考的是"上/下尿路如何区分"的关键问句。

## 二、问诊分层

**主诉**
- "发烧，腰疼，小便的时候疼。"
- 追问最难受 → "腰这儿一抽一抽地疼，走路都直不起来。"

**起病与时间**
- "大前天晚上开始的。先是上厕所疼，我以为是上火，喝了两天水。"
- 起病缓急：急，24 小时内发热 + 腰痛。

**诱因**
- 前一周憋尿多（"柜台不能离人，一坐四五个小时"）。
- 喝水少。
- **近期有性生活**（问到才含糊承认，两天前）。
- 无导尿、无泌尿系手术史。

**主要症状特点**
- 尿路刺激征：尿频（一小时两三次，每次量少）、尿急（"憋不住，一起来就得跑"）、尿痛（尿道烧灼、末端刺痛）。
- 尿液：浑浊，"像淘米水"，有异味（"味儿冲"）；**曾见一次淡红色**（问到"尿里有没有血"才说，怕血）。
- 腰痛：**右侧**腰部持续酸痛 + 阵发绞痛，叩击加重，放射至右下腹（"像有根筋扯着"）。
- 发热：39.1℃，伴**寒战**（"盖两床被子还抖"），服退热药能退，5–6 小时又升。

**演变**
- 第一天只有尿痛，第二天开始发热腰痛，逐日加重。

**伴随症状**
- 恶心 ✓，呕吐 1 次（胃内容物）
- 乏力、食欲差 ✓
- 头痛 ✓
- 无腹泻 ✗
- 无咳嗽咳痰 ✗
- 无阴道分泌物增多、无外阴瘙痒 ✗
- 无下肢水肿 ✗
- 无关节痛、无皮疹 ✗
- 无体重下降 ✗

**阴性鉴别（问到才说）**
- 无排尿中断、无尿线变细（排结石梗阻）✗
- 无剧烈肾绞痛向会阴放射（区别于输尿管结石，但仍需影像）✗
- 无高血压病史、无水肿泡沫尿史（排慢性肾病）✗
- 无糖尿病史（排复杂性因素）✗
- 无长期使用激素/免疫抑制剂 ✗
- 无近期器械操作、无妊娠（LMP 半月前，否认性生活避孕失败可能？——问到才说"我这个月应该没怀"）✗

**诊疗经过**
- 单位：无（自己在家喝水、吃了两片"三金片"）。
- 检查：无。去年体检尿常规正常。
- 治疗：三金片、布洛芬（退热）。
- 疗效：无效，越来越重。

**一般状况**

## 三、陷阱设计

1. **隐藏信息**：血尿。"尿里有血吗"→"没有吧。"→ 追"颜色有没有发红、像洗肉水"→"有一回……是有点粉红，我以为是那个来的。"（她以为是月经）
2. **隐藏信息**：性生活与妊娠可能。"最近有没有性生活"问得委婉她才会答；追问"有没有避孕、月经准不准"才说"没做措施，本来打算这次月经来了再说。"
3. **隐藏信息**：既往尿路感染史。"以前有没有过"→"前年有过一次，吃了三天药就好了。"（问出来才知道是复发）
4. **跑题**：讲银行柜台不能离岗、讲领导不给假、讲上次憋尿憋出的糗事，讲三四句。
5. **主动提问**（中段）："大夫，这个会不会影响到肾？我以后还能不能要孩子？"
6. **主动提问**（总结后）："要输液几天？我请假领导肯定不高兴。"

## 五、标准病历（考后对照）

**主诉**：尿频、尿急、尿痛 3 天，发热伴右侧腰痛 2 天。

**现病史**：患者 3 天前出现尿频（约每小时 2–3 次、每次量少）、尿急、排尿烧灼痛，尿液浑浊有异味，自认为"上火"，多饮水未缓解。2 天前出现发热，最高 39.1℃，伴寒战，服退热药可暂退但 5–6 小时复升；同时出现右侧腰部持续酸痛及阵发性绞痛，向右侧下腹放射，活动及叩击时加重，行走受限。伴恶心、呕吐 1 次、乏力、食欲减退、头痛。曾自服三金片及布洛芬无效。病程中曾一次发现尿液呈淡粉色。病前有长期憋尿（工作时数小时不能离岗）及饮水少，2 天前有性生活史。既往 2 年前有泌尿系感染史，服药 3 天治愈。无排尿中断及尿线变细，无剧烈肾绞痛向会阴放射，无水肿及泡沫尿史，无糖尿病及免疫抑制剂使用史，无近期泌尿系器械操作。

**既往史**：2 年前泌尿系感染；青霉素过敏（皮疹）；否认糖尿病、高血压、泌尿系结石及慢性肾病；无手术外伤及输血史。

**个人史**：不吸烟、不饮酒；饮水量少，有憋尿习惯。14 岁初潮，周期规则，LMP 半月前；已婚 2 年，G0，未规律避孕。

**家族史**：母亲反复尿路感染；否认多囊肾等遗传性肾病家族史。

**体格检查（要点）**：T 38.8℃，P 106 次/分，BP 112/70 mmHg；急性病容；**右肾区叩击痛阳性**，右输尿管走行区压痛；下腹轻压痛，无反跳痛；双下肢无水肿；外阴未见异常分泌物。

**辅助检查**：尿常规 WBC（+++），RBC（+），亚硝酸盐阳性，尿蛋白（+）；尿沉渣白细胞 35/HP；血常规 WBC 13.6×10⁹/L，中性 86%；CRP 96 mg/L，PCT 0.6 ng/mL；肌酐 72 μmol/L；泌尿系超声未见结石及积水；尿培养待回报（经验性用药前留取）。

**诊断**：急性肾盂肾炎（社区获得性，右肾）。

**鉴别要点**：急性膀胱炎（无发热、无腰痛、无肾区叩击痛）；输尿管结石（阵发绞痛向会阴放射、血尿、超声见结石及积水）；急性阑尾炎（转移性右下腹痛、麦氏点压痛、无尿路症状）；盆腔炎（下腹痛、宫颈举痛、分泌物增多）；肾结核（慢性、无菌性脓尿、结核史）。

## 六、考官提示

- **区分上下尿路的关键问句**是"有没有发热、腰痛、寒战"，本题的分数大量集中在这里。只问尿频尿急尿痛最多 65 分。
- 「阴性鉴别」2.5 分：合格动作是问结石（绞痛、放射、排尿中断）、问妇科（分泌物、妊娠）、问糖尿病（复杂性因素）。
- 「既往史」12 分：青霉素过敏这条极关键（选药安全），漏问的考生在实际临床属于严重缺陷；2 年前的尿路感染史属于"曾患病"，也在此项。
- 「个人史」6 分：女性患者必须问月经婚育史，本题还牵出妊娠可能性，问到即体现临床思维。
- 「医患沟通—针对患者提问」：本题的"能不能要孩子"是真实焦虑，答"先治好再备孕，用的药要避开孕期不安全的"才是专业建议。
