# 病史采集速查卡

**怎么用：** 考前 5 分钟扫一眼对应专科那几行；考完复盘时，把自己问过的和我这里的五句对一遍，缺哪句就补哪句。**不要背原句**，背的是"这一病种必须落到哪几个点"。

---

## 一、通用七问（任何一题都适用的骨架）

不管抽到什么病，这七条问全了，基础分就不会塌。

1. **起病**：什么时候开始的？第一个症状是什么？怎么起来的（突然还是慢慢）？
2. **演变**：越来越重、差不多、还是时好时坏？中间有没有好过一段？
3. **定位与性质**：具体在哪儿？什么样的感觉？会不会窜到别处去？
4. **诱因与缓解**：什么情况下犯或加重？什么情况下能好一点？
5. **伴随症状**：按系统过一遍——发热、出汗、体重、食欲、睡眠、大小便。
6. **诊疗经过**：在哪儿看的？查了什么、结果怎样？吃了什么药、吃多久、有没有效、有没有停？
7. **背景**：既往病、长期吃什么药、手术外伤、过敏、烟酒、职业、家族。

## 二、分专科速查

### 心血管（4 例）

**03 稳定型心绞痛**
1. 胸痛五要素：部位、性质、往哪儿窜（左肩/下颌/后背）、什么情况下犯（走多远、上几层楼）、持续几分钟
2. 怎么缓解的：停下就缓？含硝酸甘油几分钟起效？
3. 有没有一变天、一吃饱、一激动就犯
4. 危险因素：血压、血糖、血脂、吸烟（几支×几年）
5. 降压药还在吃吗？什么时候停的、为什么停
> ❗最易漏：吸烟只得到"三十多年"，要算成支/日 × 年；以及"血压正常就自己停了"

**13 慢性心力衰竭**
1. 气短：爬几层楼？夜里能不能平躺？几个枕头？有没有夜间憋醒
2. 下肢肿不肿？体重有没有涨？衣服鞋是不是变紧了
3. 尿量、夜里起几次
4. 诱因：最近有没有感冒、吃咸、输液，**利尿剂停了没有**
5. 基础病：高血压、冠心病、瓣膜病
> ❗最易漏：体重这条几乎没人问；别跟着"人老了就这样""是肺不好"走

**14 原发性高血压**
1. 发现多久、最高多少、平时测不测
2. 症状：头痛头晕，**打不打鼾、白天困不困**
3. 靶器官：胸闷、泡沫尿、视力模糊、一侧肢体无力
4. 继发因素（**逐项点名**）：口服避孕药、甘草话梅、止痛药、阵发性心慌出汗
5. 用药：吃什么、还吃吗、为什么停
> ❗最易漏：病人真的没症状，别反复问"哪儿不舒服"；转去危险因素+靶器官+继发因素三条线

**15 心房颤动**
1. 心慌是突然来的还是慢慢来的？**怎么好的，是不是一下就停了**
2. 一次持续多久、一个月几次
3. **有没有眼前发黑、站不稳、晕过去**
4. 卒中风险：高血压、糖尿病、心衰、以前有没有短暂脑缺血
5. 出血风险：黑便、牙龈出血、身上瘀斑、**酒一天喝多少**
> ❗最易漏：黑矇（他不觉得这算事）+ 酒量（第一次只会说"就喝点"）

### 呼吸（5 例）

**04 社区获得性肺炎**
1. 痰：什么颜色、一天多少口、有没有血丝、有没有臭味
2. 发热几天、最高多少、有没有寒战
3. 胸痛跟呼吸、咳嗽有没有关系
4. **有没有得过结核、接触过结核病人**（"小时候得过痨病"）
5. 基础病与近期吃过什么抗生素
> ❗最易漏：痰中血丝、既往结核史

**05 支气管哮喘急性发作**
1. 诱因：冷空气、油烟、花粉、运动、阿司匹林
2. 夜间或凌晨发作？能不能平躺
3. **有没有因为喘去过急诊、进过 ICU、插过管**
4. 控制药（吸入激素）规律用吗？**急救药一天几次、一个月几瓶**
5. 有没有说话说不成句、嘴唇发紫
> ❗最易漏：插管史与急救药频次——这两条直接决定轻重分级

**16 支气管肺癌**
1. 咳嗽：多少年、最近性质有没有变
2. 痰中带血：血丝还是血块、多少
3. **嗓子有没有变哑、喝水呛不呛、脸和脖子肿不肿**
4. 吸烟：一天几包 × 多少年；职业粉尘、油烟
5. 瘦了几斤、骨头痛不痛、有没有头痛
> ❗最易漏：声音嘶哑被病人当"上火"，不问就漏

**17 慢性阻塞性肺疾病**
1. 咳嗽咳痰多少年、痰什么颜色、一天多少
2. 气短分级：走多远、爬几层楼要停
3. **急性加重拆三问：去年住院几次、急诊几次、自己吃抗生素几次**
4. 吸烟包年；**职业粉尘、家里烧柴火多少年**
5. 脚肿不肿、枕头垫几个、**吸入药规律用吗、会不会用装置**
> ❗最易漏：加重次数只得到"一年犯几回"，必须拆成三个数字

**18 呼吸衰竭**
1. **先说"我向家属了解一下情况"，再补问一遍**
2. 意识：嗜睡、说胡话、叫不叫得醒
3. 诱因：**最近吃镇静药了吗（地西泮）、止咳药是不是吃多了**、有没有感染、家里吸氧开多大
4. 能不能自己把痰咳出来、痰堵不堵
5. 基础病、平时在家吸不吸氧
> ❗最易漏：一直追问答不清的患者；镇静药与止咳药过量

### 消化（6 例）

**06 消化性溃疡**
1. 疼痛节律：餐前痛还是餐后痛、夜里痛不痛、饿的时候痛不痛
2. 黑便：什么颜色、**发不发亮发黏、冲水挂不挂壁、几天了、量多少**
3. NSAIDs 点名问：芬必得、阿司匹林、头痛粉，吃多久、一天几粒
4. 酒：一天多少、多少年
5. 有没有呕血、头晕心慌（失血表现）
> ❗最易漏：黑便的"柏油样"细节；问"最近吃什么药"只会得到"就吃了点胃药"

**12 乙型肝炎肝硬化**（同时对应"病毒性肝炎"）
1. 抗病毒药：吃的什么、吃多久、**现在还在吃吗、什么时候停的**
2. 酒：一天多少、多少年
3. **父母、兄弟姐妹有没有肝病、肝癌**
4. 出血：大便黑不黑、牙龈出血、身上瘀斑
5. 腹胀、尿少、脚肿、**有没有说话糊涂、手抖**
> ❗最易漏：停药史 + 家族里"母亲肝癌走的"

**19 慢性胃炎**
1. 把"老胃病"拆回症状：部位、性质、跟吃饭的关系、多少年
2. 报警症状：**瘦了几斤、蹲下起来发不发黑、脸色、有没有呕血黑便**
3. 幽门螺杆菌：查过吗、根除过吗、**吃完药复查了吗**
4. NSAIDs、阿司匹林、活血中成药点名问
5. 酒、浓茶咖啡、吃饭规律不规律
> ❗最易漏：报警症状被病人说成"瘦了点""我低血压"

**20 结肠癌**
1. 便血：鲜红还是暗红、**跟大便混不混在一起**、是滴血还是擦纸有血
2. 排便习惯：一天几次、**大便是不是变细了、越来越细**
3. 里急后重：老想上，去了能不能拉出来、蹲多久
4. 瘦了几斤、有没有头晕乏力
5. 家族里有没有肠癌、肠息肉；做过肠镜吗
> ❗最易漏："便条变细"和"与大便相混"——这两句才推得翻"痔疮"

**21 急性胰腺炎**
1. 腹痛：哪儿、往腰背窜不窜、**弯腰抱膝能不能好受点**
2. 吐了几次、**吐完疼不疼了**
3. 诱因：昨晚喝了多少、平时一天多少多少年；**有没有胆结石**；血脂高不高
4. 发热、腹胀、放屁排便通不通
5. 以前有没有类似发作
> ❗最易漏：呕吐后不缓解（跟胃炎分开）+ 体位缓解 + 胆结石

**22 急性腹泻**
1. **量：每次多少、一天总共多少、比平时尿还多吗**
2. 性状：水样/米汤样/带黏液血、有没有臭味
3. **家里、一起吃的人有没有也拉**
4. 脱水：口渴、尿几次颜色深不深、站起来晕不晕、**三天掉了两斤**
5. 流行病学：外面吃饭、海鲜、旅行、最近吃过抗生素吗
> ❗最易漏：只问"拉几次"不问"拉多少"；同餐者要主动问

### 血液（3 例 + 3 例清单外加练）

**01 缺铁性贫血**
1. 月经：**一次几包卫生巾、有没有血块、几天干净**；体检说过子宫肌瘤吗
2. 消化道失血：黑便、便血、痔疮；查过粪便隐血吗
3. 饮食吸收：素食？浓茶咖啡？胃手术或长期吃抑酸药？
4. 贫血到什么程度：爬几层楼气短、蹲起发黑、心慌
5. 有没有想吃怪东西（异食癖）、舌头疼、指甲变脆
> ❗最易漏：月经的"量"。只问"规律吗"永远得到"规律"

**02 急性髓系白血病**
1. 发热：多少度、几天、**打了抗生素有没有退**
2. 出血：牙龈、鼻子、皮肤瘀斑、月经量、黑便
3. 骨头痛不痛，**胸骨按着疼不疼**
4. 脖子、腋下、肚子自己摸到疙瘩没有
5. 职业暴露：油漆、稀释剂、苯，干什么工种、防护做不做
> ❗最易漏："抗感染无效"这一条；只问"烧几天"不问"消炎药有没有用"

**23 原发免疫性血小板减少症**
1. 出血三处：皮肤瘀点（**没磕过自己出来的、压了不褪色**）、黏膜（牙龈、鼻、口腔血疱）、内脏
2. 月经：**几片卫生巾、有没有血块、几天**
3. 用药点名：布洛芬、头孢、减肥茶、肝素、磺胺
4. 起病前一个月有没有感冒、打疫苗
5. **头痛、呕吐、看东西模糊**（颅内出血筛查）
> ❗最易漏：把"出血"问成"贫血"；用药只问一句等于没问

**30 再生障碍性贫血**（清单外加练）
1. 三条线分头问：贫血（活动耐量掉多少）、出血（皮肤/黏膜/内脏/颅内）、感染（发热几天、哪儿、抗生素有没有效）
2. 暴露：什么工种、车间里有什么溶剂、通风怎样、戴不戴防护、干了几年
3. 药物点名：安乃近、保泰松、氯霉素、抗甲状腺药、减肥茶
4. **有没有查过肝功能、体检说肝功高吗**；输过血没有
5. **早上第一泡尿颜色深不深（像浓茶/酱油）**；兄弟姐妹小时候有没有贫血输过血
> ❗最易漏：只问一条线；暴露只问一句"接触过有害物质吗"

**31 多发性骨髓瘤**（清单外加练）
1. 骨痛五要素：部位、是不是一直疼、夜里疼醒、**活动后更疼还是好些**、越来越疼吗
2. **个子矮了没有**；有没有哪一处突然剧痛（咳一声肋骨疼）
3. 高钙：**是不是特别渴、水喝得多、几天一次大便、说话找不着词**
4. 肾：**尿里泡沫多不多、散不散**、夜里几次、肌酐查过吗
5. **体检有没有说球蛋白高、让去血液科**；一年因肺炎住几次院
> ❗最易漏："球蛋白高、让我去血液科"这条藏在诊疗经过里；高钙三问几乎没人问

**32 淋巴瘤**（清单外加练）
1. 淋巴结八问：还有哪儿有（腋下、大腿根）、多大、几个、**硬还是软、推得动吗**、疼不疼、长得多快、皮肤红不红
2. **吃过消炎药小了一点，后来又大了吗**
3. B 症状四条：发热（是不是傍晚烧、出汗就退）、**盗汗湿不湿衣服**、**瘦了几斤多久**、**洗热水澡更痒吗**
4. **喝酒以后那个包疼不疼**
5. 咳嗽气短、吃半碗就饱、鼻子塞不塞、早上回吸有没有血丝
> ❗最易漏：B 症状只问发热；"抗生素后小了一点"这个误导点不追后半句

### 肾脏（4 例）

**11 急性肾盂肾炎**
1. 尿频尿急尿痛，一天几次
2. 腰：一边还是两边、**敲着疼不疼**、往肚子窜不窜
3. 发热几天、最高多少、有没有寒战
4. **尿色有没有发红、像不像洗肉水**、一天尿多少
5. 诱因：憋尿、性生活、**有没有可能怀孕**、以前犯过没有
> ❗最易漏：血尿（她以为是月经）+ 妊娠可能

**24 肾病综合征**
1. 水肿从哪儿开始、早上眼皮肿不肿、按下去有没有坑、**体重涨了几斤**
2. **尿里泡沫多不多、细不细、散不散**
3. **两条腿肿得一样吗、有没有一边特别疼**（血栓）
4. 诱因：感染、止痛药、中草药、过敏、紫癜
5. 一天尿多少、尿色深不深
> ❗最易漏：泡沫尿、体重、单侧腿肿——三条不问就丢

**25 慢性肾脏病**
1. 往前追病因：高血压多少年、糖尿病、以前查过蛋白尿吗
2. **止痛药、去痛片、头痛粉吃了多少年、一天几片**
3. 加重因素：最近有没有感染、拉肚子脱水、自己停药、做造影
4. 尿毒症症状：夜里起几次（**跟白天比哪个多**）、皮肤痒、恶心、抽筋、乏力
5. 一天尿多少
> ❗最易漏：去痛片年限；夜尿不问"跟白天比"

**26 原发性肾小球肾炎（IgA 肾病）**
1. **嗓子疼/感冒到尿变红，隔了几天**（1–3 天还是 1–3 周）
2. **以前有没有过、一年几回**
3. 尿色：洗肉水还是浓茶、红了几天
4. 一天尿多少、**尿的时候疼不疼**
5. 血压高不高、眼睛肿不肿、腰疼不疼
> ❗最易漏：那个"隔几天"——IgA 与链感后肾炎的分水岭

### 内分泌（3 例）

**07 2 型糖尿病**
1. 三多一少，体重掉了多少斤
2. **最近两个月药断过没有、断了多久**
3. 并发症筛查：手脚麻、视力模糊、泡沫尿、伤口难愈、胸闷
4. 有没有低血糖发作（心慌、出汗、手抖、饿得慌）
5. 父母兄弟姐妹有没有糖尿病；含糖饮料、偏方、保健品
> ❗最易漏：停药史；家族史问"家里有吗"会说"没有"，要逐人问

**08 甲状腺功能亢进**
1. 怕热多汗、心慌、手抖、大便次数多
2. 吃得不少反而瘦，瘦了几斤
3. **月经量有没有变少、周期准不准**
4. 脖子粗不粗、眼睛突不突、有没有压迫感
5. **体检报告有没有哪项打了箭头、写着建议复查**
> ❗最易漏：体检报告那条；还有别顺着"就是压力大"这个归因走

**09 痛风急性发作**
1. 哪个关节、红肿热痛、几天到最疼、能不能走路
2. 诱因：酒一天多少、海鲜内脏火锅、利尿剂
3. **尿酸多少、医生让吃药吃了吗、肾功能查过吗**
4. 关节有没有硬疙瘩、有没有肾结石、夜尿多不多
5. 家里人有没有痛风
> ❗最易漏：酒只得到"偶尔喝点"；尿酸 580 却没治

### 风湿免疫（2 例）

**10 系统性红斑狼疮**
1. 皮疹：脸上蝴蝶样红斑、晒太阳后加重、脱发
2. 关节痛：对称吗、哪些关节
3. 口腔溃疡：**长在哪儿、疼不疼**（无痛性溃疡更有意义）
4. **雷诺：遇冷手指先变白、再变紫、暖了变红吗**
5. 内脏：泡沫尿、抽搐或性格改变、干咳气短、血象低过吗
> ❗最易漏：雷诺要追到"变白变紫"；别接受"过敏、上火、没休息好"这套归因

**27 类风湿关节炎**
1. 晨僵：**僵多久（超过一小时吗）、怎么才能松开**
2. 关节：两边一样吗、哪些关节、**最上面那一节指关节疼不疼**、一共几个
3. **越休息越重、活动以后反而轻**
4. 关节外：口干眼干、干咳气短、胳膊肘有没有硬疙瘩、夜里手麻
5. 家里有人得过吗；查过类风湿因子、血沉吗
> ❗最易漏：晨僵只问"有没有"不问"多久"；远端指间关节不问就没法跟骨关节炎分开

### 感染（3 例）

**12 乙型肝炎肝硬化** — 见消化科部分（同一例承担"病毒性肝炎"与"肝硬化"两条）

**28 中枢神经系统感染（化脓性脑膜炎）**
1. 头痛：哪儿、什么样的、**吐的时候是不是喷出来的**
2. 发热几天、脖子硬不硬、怕不怕光
3. **有没有糊涂、说胡话、叫不醒**
4. **有没有抽过、抽的时候什么样**
5. **耳朵流不流脓、听得清吗**；鼻子、牙齿、头部外伤、做过手术吗
> ❗最易漏：耳朵（感染来源）、意识、抽搐——三条都是重症判断的骨架

**29 败血症/感染性休克**
1. **人比昨天好还是差**（体温降了不一定是好转）
2. **尿：昨天几次、大概多少、什么颜色**
3. 有没有糊涂、说话重复、叫他反应慢
4. 感染灶：右上腹痛、皮肤眼白发黄、尿色深、胆结石史；咳嗽、尿痛、皮肤破损
5. 基础病与免疫抑制：糖尿病、激素、化疗、留置导管
> ❗最易漏：尿量与意识；感染灶不定位就只能停在"发热待查"

## 三、五个最值钱的动作

1. **所有形容词都换成数字。** "很多""挺久了""瘦了点"——追问"几次""多少天""几斤"。这一步几乎决定你能不能过 80。
2. **药名要自己报。** 问"最近吃什么药了吗"等于没问，病人只会说"没吃什么"。改成"芬必得、阿司匹林、头痛粉、中药、保健品，这些吃过吗"。
3. **问一句"以前有没有过"。** 复发与否，常常直接改变诊断和轻重判断。
4. **主动问"您还有什么想问的、有什么顾虑"。** 既是第 17 项那 5 分，也能让病人后面不再追着你问。
5. **收尾前复述一遍。** "我复述一下，您看对不对"——总结分在这里，漏项也常常在这一步被自己发现。

## 四、失分最快的十个动作

1. 病人自报诊断就顺着走："痔疮""老胃病""缺钙""淋巴结炎""就是累的"。
2. 只问"疼不疼"，不问"多久、多少、几次"。
3. 问"最近吃什么药了吗"。
4. 漏系统回顾——体重、睡眠、大小便这三样。
5. 家族史只问"家里人有没有病"，不问到具体的人。
6. 烟酒只得到"抽了很多年""就喝点"，不算成量。
7. 职业只问"做什么工作"，不问接触什么、防护如何。
8. 不总结就收卷。
9. 一次抛三个问题，病人只答最后一个。
10. 病人提问时只"嗯"一声，或者一句"别担心"就过去了。
