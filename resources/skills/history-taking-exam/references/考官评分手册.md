# 考官评分与反馈手册

本文件只负责**第三阶段：打分与点评**。写在这里的判分标尺在 `评分表.md`，本文件管流程和输出。

## 一、切换的三条纪律

1. 切换是**一次性的**：切换到考官后不再回演病人。考生若要求"再补问一句"，可以答应，但明确说"补问不再计分"。
2. 切换后第一件事是**还原，不是给分**。没有还原直接给分，分数会失真。
3. 考官身份下可以说穿一切：这道题的真实诊断、考生漏了什么、标准答案是什么。不留悬念。

## 二、步骤一：问诊实录还原

按八个维度把对话重新归档，**只记考生问到／没问到，不评价**。用这个骨架：

```
【还原：考生实际覆盖到的信息】
1 基本信息：姓名✓ 年龄✓ 病历号✗ 职业✓ 籍贯✗ 自我介绍（报了姓名，没报身份）
2 主诉与起病：起病时间✓（问出"过完年"，未追具体月数）起病缓急✓
3 诱因：✗ 未问
4 主要症状：性质✓ 部位✓ 程度✓（"百十米"）放射✓
5 演变过程：✓ 问了两周内的加重
6 伴随症状：出汗✓ 恶心✓ / 阴性鉴别：反酸✗ 与呼吸关系✗ 按压痛✗
...
```

要点：
- 打 ✓ 的标准是"考生明确问过，患者给出了可判读的回答"，含糊带过不算。
- 考生问了两遍同一件事只算一次。
- 患者主动说出来的、而考生没问的，标为「主动」，**该项不计分**（这是真实考场的规则）。
- 时间信息要如实记：问出"过完年"和问出"3 个月前"在「时间」这一项上都可以给满分，不必强求精确日期。

## 三、步骤二：逐项打分

按 `评分表.md` 的 18 行逐项给分，每项**必须写一句理由，引用考生原话或原行为**。

给分原则（校准用，防止手松手狠）：
- **只看有无，不看漂亮。** 问到了就给，问得笨但问到了照样给分。
- **部分给分是常态。** 5 分的项给 3 分很正常；只有全漏才给 0。
- **不发善心分。** 考生"应该是想问的但没问出口"不算。患者主动提供的信息不算考生得分。
- **技巧类（12–18）看全程**：出现一次扣一次，扣完为止，不做整体印象加减。
- 若某一行无法判定（例：患者没给考生提问机会），按 0 分计，并在理由里注明"未出现"。

输出表格格式：

| # | 评分项目 | 标准分 | 得分 | 判分依据 |
|---|---|---|---|---|
| 1 | 自我介绍（姓名／身份） | 2 | 1 | 报了"内科住院医师"，未报姓名 |
| 3 | 主诉：起病情况与时间 | 5 | 5 | "什么时候开始的"→"过完年"；"一开始怎么起的"→"爬楼时疼" |
| … | | | | |
| — | **合计** | 100 | **XX** | |

分数要求：整数或 0.5，不出现 2.3 这种数。

## 四、步骤三：判定与总评

- **≥80：通过**（真实考站按 80 分合格线，不是 60）。
- **70–79：临界**，指出只差哪几项就能过，通常 2–3 个具体动作。
- **<70：不通过**，问题通常是结构性的（没有主线、不总结、零共情），不是漏一两个点。

总评一句话，别写"整体不错，继续努力"这种。要写成：**"你的采集够用，但表达不够——分数丢在沟通那 20 分里，不在医学内容上。"**

### 如果 SP 阶段多说了什么：以脚本为准，不以自己说过的话为准

演病人的时候难免补细节。评分时按下面三条处理，不许含糊过去：

1. **打分一律以病例文件为准。** 脚本里写"第一次问只说家里人都挺好"，考生只问了"家里有没有类似情况"就得到了表哥的信息——这条就算没拿到。不能因为自己当时演松了，就顺手给分。
2. **发现自己演超了，要主动说明。** 在「问诊实录还原」里单列一行：`⚠ 演出偏差：XX 这句是我临场补的，脚本里没有，不计入你的得分`。藏着不说，考生会把自己没问到的信息当成问到了。
3. **演出偏差影响了判断，就要标出来。** 如果因为多给了一句而让某项分虚高，写清"这一项若严格按脚本应为 X 分"。宁可给低分再解释，也不能给高分不讲。

同时记一句给下次用：**偏差不是考生的错，是演的问题**，措辞不要写成"你运气好，我多说了"。

## 五、步骤四：反馈的正确写法

### 必须有的三块

**1. 失分排名（只列前三）**
按丢分多少排序，每条写"丢几分 + 具体改成什么话"。

> ① 阴性鉴别症状 −2.5：你问了"还有别的不舒服吗"，这是开放问法，得不到判别信息。改成成对追问：「疼的时候有没有反酸、烧心？」「跟呼吸有关系吗，深呼吸会不会更疼？」
> ② 总结 −5：你说"那我去开检查"，直接跳过了复述。改成三句话：「我理一下——您是从过年后开始，活动时胸口压着疼，歇几分钟能缓，最近两周走百十米就发，还出汗。是这样吗？」
> ③ 医保 −2：全程没问。收尾加一句「您有医保吗？家里经济上有没有压力？」就够。

**2. 标准病历对照**
把本题的标准病历（见病例文件的「标准病历」节）给出，让考生自己比：主诉怎么写、现病史哪几个要素自己漏了、诊断是否对、鉴别方向是否想到。

**3. 三条可以明天就用的动作**
不要写"加强练习""多看书"。写成可执行的一句话：
- 「进门前三句固定：问好＋报姓名身份＋核对姓名年龄病历号。」
- 「每问到一个阳性症状，立刻补一个鉴别阴性症状，形成条件反射。」
- 「收尾固定四步：复述→说方向→说下一步→问医保。」

### 不要写的

- 空泛鼓励：「基础不错」「思路清晰」——没有信息量。
- 复述评分表条目当评语。
- 拿"考试紧张"当解释。紧张是事实，不是原因，改法要落到动作上。

## 六、连续多轮时的处理

用户可能连考几道，也可能隔几天再来。跨轮的记忆靠**训练记录文件**，不靠对话里的印象——对话会被压缩，印象会失真。

### 每轮结束必须追加一行

写进记录文件（路径与格式见 SKILL.md 第六节）。要点：

- **只追加，不改写旧行**。别为了"整理格式"重排、重算历史，那样累计就不可信了。
- 主要失分项填 1–3 个短名，用顿号分隔。写短名（「晨僵时长」），不要写整句话。
- 写不进去不要紧，但要在点评末尾说一句「这轮没能存进记录」，别装作存上了。

### 开考时先读，再说话

读出总场次、均分、已练过的题号。开场只加一行 `第 6 场｜均分 78.3`，**不要把统计铺开成一段话**——那是干扰，不是信息。

用户问「我练过哪些」「上次多少分」「我哪项最差」，**去查文件，不要凭记忆答**。查不到就直说查不到。

### 老毛病的判定线

把记录里「主要失分项」一列拆开计数：

| 出现次数 | 怎么说 |
|---|---|
| 1 次 | 这轮的问题，正常写 |
| 2 次 | 可以点一句「第二次出现了」 |
| ≥3 次 | 才算老毛病，单列一节，措辞可以重：这不是不会，是习惯没改 |

**不许把只出现一两次的失分叫"老毛病"**，那会让考生以为自己积习难改，其实只是这题没问到。

### 其它

- 每轮独立评分，不因为上一轮分数高就放松。
- 到第 3 场起，点评只讲**重复出现**的失分，不再复述单轮细节。
- 用户删了记录文件，就当他没练过。不要去别处找回，也不要试图重建。

## 七、常见情形裁决表

| 情形 | 裁决 |
|---|---|
| 考生问"您还有哪里不舒服"，患者答了一个 | 伴随症状给 2.5 的一半（1–1.5），阴性鉴别仍 0 |
| 考生问了家族史但只问"家里有人得过吗" | 类似疾病 2.5 给；两系三代 0 |
| 考生问了"家里父母身体怎么样" | 视同两系三代问到了一半，给 1–1.5 |
| 考生让患者自己说"还有什么要补充的"代替总结 | 总结项给 1 分 |
| 考生主动问"您还有什么想知道的""还有什么顾虑"，并把患者提的问题逐条答了 | 第 17 项（患者提问 5 分）按回应质量给 4–5 分；SP 剩余未抛出的问题不再抛，**不因"SP 没发问"而扣分** |
| 考生主动开了口子，患者说了顾虑，他只"嗯"了一声没给任何建议 | 第 17 项给 1–2 分 |
| 考生全程没给患者提问的机会，也没接住 SP 抛出的一两个问题 | 第 17 项 0 分；并在总评点明"关掉了患者开口的口子" |
| 考生给了诊断建议但用词很专业，患者没听懂 | 初诊沟通 3 分（内容对，表述未到位） |
| 考生在问诊中接了一次电话／离开场景 | 技巧类各项按实际表现，态度项最高 3 分 |
| 考生全程只问 8 分钟就说结束 | 正常评分，另注明用时，并提示真实考场 20 分钟足够问全 |
| 考生问"我上次考多少分""我练过哪些题" | 去读训练记录，按表里的原文报数；查不到就说查不到，**不许凭印象估** |
| 训练记录写不进去（只读、无权限） | 点评照常完整输出，末尾加一句"这轮没能存进记录"，不解释技术原因 |
| 抽到 30–32 中任一道（清单外加练） | 开场必须写明"清单外加练题，不在考纲范围"；打分照常，但总评里要提醒这不是考纲内容 |
| 考生说"我练了这么多题应该没问题了吧" | 不许附和。要讲清练习分与考场分的差别（真人 SP、时限压力、考官在场） |
