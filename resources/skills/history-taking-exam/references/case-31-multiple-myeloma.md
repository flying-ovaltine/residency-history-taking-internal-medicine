# 病例 31 · 多发性骨髓瘤（血液内科）

> **清单外加练病例。** 官方「建议选用的病种」血液内科只有"贫血、特发性血小板减少性紫癜、白血病"三个大类，本病例不在该清单内，仅用于血液方向加练。抽到它时要在开场注明"清单外加练题"。

**对应病种**：血液内科 — 贫血/血液系统肿瘤（多发性骨髓瘤，清单外代表病例）
**难度**：★★★★
**主线**：老太太腰背痛半年。考的是"骨痛 → 贫血 → 肾损 → 高钙"这条链，以及能不能不把腰背痛当腰椎病。

## 二、问诊分层（问到才答，不主动）

**主诉**
- 问哪里不舒服 → "腰疼，后背疼，半年了。"
- 追问最在意的 → "晚上疼得翻不了身，坐起来得扶着。"
- **注意：她只说骨痛，贫血、泡沫尿、口渴便秘都不会主动说。**

**骨痛（本题第一核心，必须问全五要素）**
- 部位：**追问** ——"腰、后背，两边肋骨也疼，有时候胸口正中疼。"（腰骶、肋骨、胸骨）
- 性质：追问——"闷闷的疼，不是针扎，一直疼。"（**持续性，非发作性**）
- 与活动关系：**追问"活动以后好点还是更疼"** → "越动越疼，躺着好一点，但躺着也疼。"（**活动后加重、休息不完全缓解，与肌肉劳损不同**）
- 夜间痛：✓ "半夜疼醒，得起来坐一会儿。"
- 与体位关系：追问——"侧躺能好点，平躺最疼。"
- 起病与进展：**追问"越来越疼还是差不多"** → "越来越疼，半年前走两站路没事，现在走半条街就得歇。"
- 身高变化：**追问"个子矮了没有、裤腿长了没有"** → "去年量的矮了三公分，我还说人老了缩了。"（**椎体压缩，高价值线索**）
- 外伤与跌倒：追问——"没摔过。"
- 病理性骨折：**追问"有没有哪个地方突然特别疼、动不了"** → "上个月咳了一声，这边肋骨疼了好几天。"（✓）
- 推拿理疗史：**追问"做过什么治疗"** → "推拿十几次，还贴膏药、拔罐，越做越疼。"

**贫血与出血（第二条线）**
- 乏力：✓ 进行性
- 头晕：✓ 体位性
- 心悸气短：✓ "上三楼得歇。"
- 面色：家人说"黄白黄白的"
- 鼻出血、牙龈出血：追问——"刷牙出血，鼻子出过一回。"
- 皮肤瘀斑：追问——"腿上有两块青的。"（✓）
- 黑便、血尿：**明确追问** ✗

**高钙表现（第三条线，几乎没人问，本题最能拉分）**
- 口渴、多饮：**追问"这段时间是不是特别渴、水喝得多"** → "是渴，一天喝两大壶。"
- 多尿、夜尿：✓ "夜里起来三回。"
- 便秘：**追问"大便干不干、几天一次"** → "三四天一次，干得很，开塞露都用上了。"
- 恶心、呕吐、食欲差：✓ "不想吃饭。"
- 乏力加重、嗜睡、反应慢：追问——"有时候说话找不着词，我女儿说我糊涂。"（✓ 意识改变）
- 骨痛加重：✓
- 肾结石史：追问——"没查出过石头。"

**肾脏损害（第四条线）**
- 泡沫尿：**追问"尿里有没有泡沫、细不细、散不散"** → "有泡沫，好多，早上最厉害，冲不下去。"
- 尿量：追问——"量不少，就是夜里多。"
- 夜尿次数：✓ 3 次（**与白天比哪个多**）
- 水肿：追问——"脚踝有点肿，按下去有个坑。"
- 肌酐、尿检：**追问"最近查过肾功能吗"** → "去年查过，说肌酐高了一点，让我复查我没去。"
- 腰痛性质与肾区痛：**追问"腰疼是一边还是两边、跟尿有没有关系"** → "两边都疼，跟尿好像没关系。"

**反复感染（第五条线）**
- 反复感冒、肺炎：**追问"一年感冒几次、有没有得过肺炎"** → "今年住了两回院，都是肺炎。"
- 发热：✗ 近期不烧
- 带状疱疹：追问——✗

- 皮肤改变：追问——"眼眶周围有没有发紫、皮肤有没有变厚" → "眼皮有点青，我以为是没睡好。"
- 腹泻与便秘交替：✓ 有时拉肚子
- 心累气短加重：✓

**阴性鉴别（问到才说没有）**
- 狼疮样皮疹、光过敏、口干眼干：✗（口干有，但**眼干无**）

- 长期激素使用：✗
- 家族肿瘤史：追问——"我哥胃上有过病，没查清楚。"

**诊疗经过**
- 单位：社区卫生服务站、推拿馆、私人中医。
- 检查：**追问才有** ——"去年体检抽血，说血里球蛋白高，让我去血液科看，我怕，没去。"（✓ **MGUS/单克隆带线索，本题最高价值**）

**一般状况**

- 大便：便秘三四天一次。

## 三、陷阱设计

1. **核心陷阱：顺着骨密度报告走。** 她带着"骨质疏松"的诊断来，一开口就说"我缺钙"。若考生接一句"那补钙就行"，本题直接失分。必须重新把骨痛拆开问（部位、性质、夜间痛、活动关系、进展速度、骨折史、身高变化）。
2. **身高缩了 3 cm 与"咳一声肋骨疼"两处都不主动说**：必须问"个子矮了没有""有没有哪个地方突然特别疼"。这是椎体与肋骨病理性骨折的直接证据。
3. **"血里球蛋白高、让我去血液科"藏在诊疗经过里**：只问"做过什么检查"会得到"查过骨密度"。必须问"抽血有没有哪项不正常、医生有没有说过要去哪个科"。
4. **高钙三问（口渴多饮、便秘、意识模糊）几乎没人问**：这三条一整套，问出来就能上 85。特别"三四天一次大便""说话找不着词"要问得很具体，问"消化好不好"得不到。
5. **泡沫尿与夜尿要问细节**：问"小便正常吗"会得到"还行"。必须问"有没有泡沫、散不散""夜里几次、跟白天比哪个多"。
6. **反复肺炎不问就漏**："今年住了两回院，都是肺炎"藏在追问里。要问"一年感冒几次、有没有因为肺炎住院"。
7. **手麻与舌大极易漏**：半夜手麻（腕管综合征）、舌体肥大、眼睑发青，三项都是淀粉样变线索，全在"问才答"里。
8. **体重只问"瘦了吗"**：得到"瘦了点"，必须问几斤——十斤。
9. **初始否认**：问"有没有其他病"她会说"没有，就是骨头"。别停在第一层，要逐项点名问。
10. **跑题**：讲推拿师傅怎么说的、讲邻居老太太摔断髋骨住院、讲女儿要接她去杭州住，一次能讲三四分钟。
11. **主动提问**（中段）："大夫，我这个是不是就是骨质疏松？我钙片吃了两年了，怎么越吃越疼？"
12. **主动提问**（总结后）："我听说这个病要化疗，我这把年纪受得了吗？会不会瘫在床上？"
13. **主动提问**（若提到住院）："住院要花多少钱？我退休金一个月三千多，能报多少？"

## 六、考官提示

- **本题第一考点是"不跟着骨质疏松走"**：病人自带诊断，还说自己缺钙。考生若接受归因、不重新拆解骨痛，本题上限就在 65。
- **骨痛五要素（部位/性质/夜间痛/与活动关系/进展速度）** 问到四项以上给满分，问到三项给半分。**再加身高变化与病理性骨折史两条，才够 85。**
- **"球蛋白高、让我去血液科"是本题分值最高的一句话**：只在"诊疗经过"里追问才会出来。没问到的，"既往史与诊疗经过"这一行扣分，且鉴别诊断分也扣。
- **高钙三联（口渴多饮、便秘、意识改变）与肾损（泡沫尿、夜尿、肌酐）必须成组问**，这是骨髓瘤 CRAB 的一半。只问"小便正常吗"给半分。
- **反复感染要问次数与部位**："一年感冒几次""有没有因肺炎住院"，问"容易感冒吗"只得一半。
- **手麻、舌大、眼睑发青是加分项**：问到任一项并能联系淀粉样变，可上 88。
- 沟通考点有两处：一是病人问"是不是骨质疏松"时的解释（要说明为什么不是，不能只否定）；二是问"化疗受不受得了"时，要谈获益与耐受评估，不能一口说"您年纪大了别治了"。这两处各占"医患沟通"1 分。
- 若考生全程围绕"腰疼"问，未问贫血、未问泡沫尿、未问口渴便秘、未追问球蛋白，本题通常落在 52–64 分。
