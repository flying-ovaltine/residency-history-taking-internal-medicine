# 病史采集考站陪练 · 使用说明

这是一个 WorkBuddy 技能包，用来练**浙江省住院医师规范化培训结业考核·病人接诊站·病史采集**。

装好之后只有两句话要说：

- **「开始考试」**：它随机抽一道题，读完病例就直接进角色，病人已经坐在诊室里等你问。你说什么都按问诊处理。
- **「结束考试」**：它立刻停止扮演，翻回整段对话逐条还原你问了什么、漏了什么，按 100 分表逐项打分，给出扣分点（丢几分、丢在哪一行、当时该怎么问）和改进意见，最后给该例的标准病历对照。

中途想加练、想问评分标准，直接说就行，不算考试内容。

## 一、怎么装

**方式 1：上传（推荐，适合发给同学）**

1. 打开 WorkBuddy，左侧点「专家·技能·连接器」，选「技能」页签；
2. 右上角「添加技能」→「上传技能」；
3. 把 `history-taking-exam.zip` 拖进去，或点选文件；
4. 提示安装成功即完成，不用重启。

**方式 2：手动放目录（适合会折腾的）**

把解压出来的 `history-taking-exam` 整个文件夹放到：

```
~/.workbuddy/skills/history-taking-exam/
```

Windows 上就是 `C:\Users\<你的用户名>\.workbuddy\skills\history-taking-exam\`。放好后刷新技能列表。

**方式 3：项目级共享（适合一个科室/基地一起用）**

放到项目目录下的 `.workbuddy/skills/`，技能就跟着项目走。把项目文件夹发给别人，对方打开就有同一套。

## 二、怎么触发

装好之后可以这样说（这几种说法都能认出这个技能）：

- 「模拟一道病史采集题，你当 SP 病人，我当考生」
- 「考我病史采集，按浙江省结业考核的评分表打分」
- 「只讲病史采集的评分标准和常见扣分点」（不出题，只讲标准）
- 「我总结病史这块老丢分，只练这一段」（单点训练）
- 「来一道血液的加练」（抽清单外的 30–32，会注明是加练题）
- 「我练过哪些题」「我上次多少分」「我最差是哪项」（查训练记录，不用重考）

**最稳的是点名**：说"用 history-taking-exam 这个技能考我一道病史采集"。

## 三、里面有什么

|---|---|
| `SKILL.md` | 主流程：抽题 → 当病人 → 切换考官 → 打分 |
| `references/评分表.md` | 官方 100 分表拆成 18 行可勾选清单，含判分标尺、高频漏 33 分 |
| `references/SP扮演手册.md` | 怎么演病人：不主动、不送分、四类陷阱、按角色提问的提问池 |
| `references/考官评分手册.md` | 怎么还原问诊、逐项给分、写反馈 |
| `references/case-*.md` | 32 例病例脚本（29 例考纲内 + 3 例血液加练），含 SP 角色卡、分层病史、埋的坑、标准病历 |
| `references/速查卡.md` | 32 例 × 5 句必须问到的问句，一页看完；另附通用七问、五个最值钱的动作、失分最快的十个动作 |

| 血液 | 贫血 / ITP / 白血病 | 01（缺铁）/ 23 / 02（AML） |
| 肾脏 | 肾病综合征 / 尿路感染 / CKD / 原发肾小球肾炎 | 24 / 11（肾盂肾炎）/ 25 / 26（IgA 肾病） |
| 内分泌 | 糖尿病 / 甲亢 / 痛风 | 07 / 08 / 09 |
| 风湿免疫 | SLE / 类风湿关节炎 | 10 / 27 |

另有 **3 例清单外血液加练**（再障 30 / 多发性骨髓瘤 31 / 淋巴瘤 32）。它们不属于考纲范围，**默认不进随机抽题池**，只有你明确说"来一道血液的加练"才会抽到，抽到时开场会写明「清单外加练题」。

清单内每个病种目前只有一例代表病例（如"贫血"只做了缺铁性贫血、"白血病"只做了 AML），同一病种下的其他亚型不在库内；血液方向想要更多亚型，可以看 30–32 这三例加练。要补，按第五节的加法新建即可。

## 四、用之前该知道的四件事

**1. 合格线是 80，不是 60。** 这一站病史采集和体格检查各 100 分、取平均，任一项低于 80 整站不合格（单站淘汰）。

**2. 这个技能只覆盖病史采集，不管查体。** 查体那一半得另外练。别把这里的 85 分当成整站稳了——病史采集 85、查体 75，一样是不合格。

**3. 「主要症状和发病过程」是 8 分。** 网上流传的部分评分表截图把这一行印成 4 分，是排版错误；只有 8 分才能和其余各项加总为 100。

**4. 这些病例是训练脚本，不是考纲原题。** 病种范围取自官方"建议选用的病种"清单，具体临床内容按真实病例特征编写，不涉及任何真实病人信息。真实考站用的是临床真实病人或经过培训的 SP。

## 五、想改

- 加病种：在 `references/` 下按现有格式新建一个 `case-NN-病名.md`，然后在 `SKILL.md` 末尾的病例库索引表里补一行。
- 改判分尺度：只改 `references/评分表.md`，别动 `SKILL.md` 里的流程。
- 加一句速查问句：改 `references/速查卡.md`，它是独立文件，不影响判分。
- 挪训练记录位置：改 `SKILL.md` 第六节的路径；记录文件本身是纯 Markdown 表格，可以直接用 Excel 或表格工具打开看趋势。
- 想上架技能市场：需要给 `SKILL.md` 的 frontmatter 补 `display_name`、`display_name_en`、`description_zh`、`description_en`、`examples_zh`、`version`、`author` 等字段，然后走开放平台（open.workbuddy.cn）提交审核。普通分享不需要这一步。

## 六、提醒

这个技能会扮演病人跟你对话，评分完全按你给的那张官方表来，不给安慰分。如果某道题分数低，先看「扣分点」那一节写的具体改法，别只看总分。
