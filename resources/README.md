# 住培-规培结业考病史采集内科

一个 Agent 型专家：同时扮演浙江省住院医师规范化培训结业考核「病人接诊」考站的标准化病人与考官。考生说「开始考试」后先选普通模式还是实战模式，再以病人身份开诊；说「结束考试」后按官方 100 分表逐项判分、给扣分点与改进意见。实战模式下病人隐瞒病史与检验单，要反复追问才一层层给。

## 类型

Agent 型（单角色），内部附带 `history-taking-exam` 技能包，含全部 32 例病例脚本、评分表、SP 扮演手册、考官评分手册和速查卡。

## 病例覆盖

按官方《临床实践能力考核规程（内科）》「建议选用的病种」8 个专科、30 个条目配齐，29 例脚本覆盖全部 30 条（乙肝肝硬化一例同时承担"肝硬化"与"病毒性肝炎"）：

| 专科 | 条目 | 对应病例 |
|---|---|---|
| 心血管内科 | 心力衰竭、高血压、心律失常、冠状动脉粥样硬化性心脏病 | case-13 / 14 / 15 / 03 |
| 呼吸内科 | 肺炎、支气管肺癌、慢性阻塞性肺疾病、呼吸衰竭、支气管哮喘 | case-04 / 16 / 17 / 18 / 05 |
| 消化内科 | 慢性胃炎、消化性溃疡、结肠癌、肝硬化、急性胰腺炎、腹泻 | case-19 / 06 / 20 / 12 / 21 / 22 |
| 血液内科 | 贫血、特发性血小板减少性紫癜、白血病 | case-01 / 23 / 02 |
| 肾脏内科 | 肾病综合征、尿路感染、慢性肾脏病、原发性肾小球肾炎 | case-24 / 11 / 25 / 26 |
| 内分泌科 | 糖尿病、甲状腺功能亢进症、痛风 | case-07 / 08 / 09 |
| 风湿免疫科 | 系统性红斑狼疮、类风湿性关节炎 | case-10 / 27 |
| 感染科 | 病毒性肝炎、中枢神经系统感染、败血症/感染性休克 | case-12 / 28 / 29 |

另有 3 例清单外的血液加练（case-30 再生障碍性贫血、case-31 多发性骨髓瘤、case-32 淋巴瘤），不进随机抽题池，仅当用户明确要求加练时抽取并注明。

## 使用

四句口令：

- 「开始考试」——先问普通还是实战模式，选定后抽题开场
- 「开始考试，来点难度」——跳过询问，直接进实战模式
- 「结束考试」——停止扮演，出完整评分报告
- 「开始考试，来一道血液科的」——按专科定向出题

中途问评分标准、问诊技巧、常见扣分点不会打断流程，也不会计入成绩。

## 评分口径

- 官方 100 分表拆成 18 行，每行有最小得分点和判分标尺
- 合格线 80 分，不是 60 分
- 「主要症状和发病过程」是 8 分（每项 4 分×2），部分流传截图印作 4 分属排版错误
- 病史采集与体格检查各 100 分取平均，任一项低于 80 整站不合格；本专家只练病史采集这一半
- 不给安慰分；发现演出偏差时单列说明但不改判

## 边界

仅用于考试训练与教学模拟，不构成医疗建议。病例、病人、检查结果均为虚构，不含任何真实患者信息。

## 安装与分享

放到专家目录后运行注册脚本：

```bash
python3 scripts/register_expert.py <expert-dir>
```

打包分享：

```bash
python3 scripts/package_expert.py <expert-dir>
```
